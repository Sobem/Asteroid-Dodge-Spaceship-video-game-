This repository is meant to showcase a basic spaceship video game project made using Pygame



In case you wish to run this project it's important to keep in mind that:
1. This project uses the python package pygame which can be run on most local (not cloud-based) code editors. My personal favorite is Thonny but applications like VS Code also work
2. To properly run the program you'll need to download the image and music files provided and **importantly** link the proper file paths in the program
